# חומרי לימוד במדעי בריאות: מדריך הפעלה ותחזוקה

אתר סטטי בעברית (RTL) שמתארח ב-GitHub Pages. כל התוכן נשמר בקובץ אחד, `data/library.json`, וניהול התוכן נעשה דרך `/admin` בלי לערוך קוד.

## מבנה התיקייה

| נתיב | תפקיד |
|---|---|
| `index.html`, `js/app.js`, `css/style.css` | האתר הציבורי |
| `admin/index.html`, `js/admin.js`, `css/admin.css` | ממשק הניהול |
| `config.json` | שם הספרייה, תיאור, מייל, וואטסאפ ופרטי ה-repo |
| `data/library.json` | הנושאים והכלים (זה מה שממשק הניהול מעדכן) |
| `assets/topics/` | תמונות הנושאים |

## שינוי שם או פרטי קשר
עורכים את `config.json` (`siteTitle`, `tagline`, `contactEmail`, `contactWhatsapp`) ושומרים.

## תמונות לנושאים
1. שמרו את התמונה בתיקייה `assets/topics/`, למשל `cardiology.jpg` (מומלץ יחס 16:10, רוחב כ-800 פיקסלים).
2. בממשק הניהול, בעריכת הנושא, רשמו בשדה "נתיב תמונה": `assets/topics/cardiology.jpg`.
3. נושא ללא תמונה מציג את האייקון שלו.

## הרצה מקומית לבדיקה
הדפדפן לא טוען קבצי נתונים מ-`file://`, לכן מפעילים שרת מקומי פשוט:

```bash
py -m http.server 8080
```

ואז נכנסים ל-`http://localhost:8080`.

## פרסום ב-GitHub Pages (חד־פעמי)
1. ב-GitHub: **New repository**. שם מוצע: `health-sciences-library`. ציבורי (Public).
2. מעלים אליו את כל תוכן התיקייה הזו (שורש ה-repo הוא התיקייה עצמה).
3. ב-Settings ← Pages: Source = *Deploy from a branch*, Branch = `main`, תיקייה `/ (root)`.
4. הכתובת תהיה `https://<שם-משתמש>.github.io/health-sciences-library/`.
5. ב-`config.json` ממלאים `repo.owner` ו-`repo.name` (לא חובה, חוסך הקלדה בכניסה לניהול).

## יצירת טוקן למנהל (חד־פעמי לכל מנהל)
1. ב-GitHub: Settings ← Developer settings ← Personal access tokens ← **Fine-grained tokens** ← Generate new token.
2. Repository access: **Only select repositories**, ובוחרים את ה-repo של הספרייה.
3. Permissions ← Repository permissions ← **Contents: Read and write**.
4. מעתיקים את הטוקן ומדביקים אותו במסך הכניסה של `/admin`. הוא נשמר רק בדפדפן הזה.

מנהל נוסף: מוסיפים את חשבון ה-GitHub שלו ב-Settings ← Collaborators (עד שלושה), והוא יוצר לעצמו טוקן כנ"ל.

## עבודה יומיומית בניהול
- **הוספת כלי:** בוחרים נושא בעץ ← "כלי חדש בנושא הזה" ← ממלאים שם, תיאור וקישור ראשי.
- **מסמכים נלווים:** בכרטיס הכלי, "+ מסמך". כפתור "בדיקה" פותח את הקישור כדי לוודא שהוא עובד.
- **שיוך לכמה נושאים:** בכרטיס הכלי, מסמנים כמה נושאים ובוחרים אחד כ"מיקום ראשי".
- **שינוי סדר:** גוררים (או חצי ▲▼ בטלפון) נושאים בעץ וכלים ברשימה.
- **הסתרה:** תיבת "הסתר" בנושא או בכלי. מחיקת נושא חסומה כל עוד יש בו כלים או תתי־נושאים.
- **פרסום:** לחצן "פרסם שינויים". האתר מתעדכן תוך כדקה בערך.
- **גיבוי:** "ייצוא גיבוי" מוריד קובץ JSON. בנוסף, היסטוריית ה-commits ב-GitHub שומרת כל גרסה.

## מקורות לקבצים
קבצים נלווים מומלץ לשמור ב-Drive או ב-OneDrive ולקשר אליהם. ודאו שהשיתוף מוגדר כ"כל מי שיש לו קישור יכול לצפות".
